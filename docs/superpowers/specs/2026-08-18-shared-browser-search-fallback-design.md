# 共享浏览器联网搜索兜底设计

## 目标

当轻量 HTTP 搜索和独立 Playwright 搜索都没有拿到结果时，让智能体自动转向右侧共享浏览器继续搜索；普通搜索成功时不打开浏览器面板。

## 方案

保留现有两级搜索实现，在失败结果中返回结构化、可执行的下一步提示：先尝试 `web_search_baidu`，仍失败时调用 `browser_open` 打开编码后的百度搜索 URL，再通过 `browser_snapshot`、`browser_fill` 和 `browser_click` 继续操作。`browser_open` 仍由智能体实际调用，以便沿用现有会话、Viewer 事件和右侧面板绑定链路。

## 边界

- 不在搜索工具内部直接创建共享浏览器，避免绕过 `browser_session` 上下文和面板事件。
- 不改变普通搜索的返回格式和成功路径。
- 只对“无结果/异常”返回浏览器兜底提示；验证码仍交给人工接管。
- 搜索 URL 继续经过浏览器现有 SSRF 与请求校验。

## 验证

覆盖 HTTP 搜索无结果、Playwright 搜索无结果和搜索异常三类返回，确认都携带 `browser_open`、正确的百度搜索 URL，并保持成功结果不变。
