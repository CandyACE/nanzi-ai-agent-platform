# 画布打开后自动钉住设计

## 目标

用户通过消息链接或工作区文件打开画布后，画布默认处于已钉住状态；用户点击右上角图钉可以取消钉住，取消后在当前画布保持取消状态。

## 方案

由共享的 `useWorkspaceCanvas` 持有 `canvasPinned` 状态。每次画布内容成功打开时将该状态设为 `true`，关闭画布不强制修改状态，用户通过 `ChatCanvas` 现有的 `v-model:pinned` 双向绑定手动改为 `false`。下一次成功打开内容时再次设为 `true`。

这样所有打开入口（消息内画布链接、工作区文件预览、直接文件预览和对比预览）使用同一条行为路径，且不会因为用户手动取消而在同一次打开期间被恢复。

## 测试

在现有共享 composable 行为测试中覆盖：首次打开自动钉住；手动将钉住状态改为 `false` 后保持取消；关闭并再次打开后重新自动钉住。保留现有工作区预览切换、直接内容和错误处理行为。
