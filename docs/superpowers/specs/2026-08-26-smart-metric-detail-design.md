# 推荐指标详情弹窗设计

## 背景

智能指标发现弹窗当前以卡片展示 AI 推荐指标。卡片正文中的描述和计算逻辑使用截断展示，用户无法查看单个指标的完整内容；同时卡片整体点击已经承担“选择/取消选择”职责，不能直接把卡片点击改成查看详情，否则会破坏批量保存流程。

## 目标

- 让用户能查看单个推荐指标的完整业务信息和计算逻辑。
- 保留现有卡片整体点击切换勾选的行为。
- 让查看详情与勾选操作有明确、互不冲突的入口。
- 详情只展示推荐结果，不新增接口、不改变保存数据和批量保存逻辑。

## 交互方案

采用方案 A：在每张推荐指标卡右上角新增“查看详情”按钮。

- 点击卡片主体：仅切换当前指标的选中状态。
- 点击右上角“查看详情”：打开详情弹窗，并阻止事件冒泡，不改变选中状态。
- 详情弹窗关闭后回到推荐列表，已选状态、全选状态和保存数量保持不变。
- 详情按钮在桌面端显示文字，在窄屏下保留清晰的图标与可访问性标题。

## 详情内容

详情弹窗使用现有推荐指标对象，不请求后端。按以下层级展示：

1. 指标显示名称、物理标识和单位。
2. 业务描述；没有描述时展示“暂无描述”。
3. 完整计算逻辑/SQL，使用等宽字体和可滚动容器，避免长内容撑破弹窗。
4. 标签（存在时展示）。
5. 底部操作：关闭；如需保存，用户回到列表后通过原有“保存选中指标”统一保存。

## 状态与边界

- 详情索引使用当前推荐列表项的索引；列表重新生成或关闭弹窗时清理详情状态。
- 推荐列表为空、AI 生成中和配置页不展示详情状态。
- 点击遮罩或关闭按钮关闭详情；生成中/保存中仍遵循外层弹窗的关闭限制。
- 详情内容全部来自当前已加载的推荐结果，避免因额外请求产生权限、数据源或状态不一致。
