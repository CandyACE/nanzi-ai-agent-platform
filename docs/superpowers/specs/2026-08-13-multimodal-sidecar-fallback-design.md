# 非多模态会话的图片旁路解析

日期：2026-08-13

状态：实现中

## 目标

会话当前模型不支持多模态时，不整轮换模型。用系统默认多模态模型把本轮图片解析成文字，注入原模型上下文并告知用户。未配置或解析失败则降级为现有拦截提示。

## 行为

1. 本轮无图片，或当前模型已声明多模态：保持 Vision 直连，不旁路。
2. 本轮有图且当前模型明确不支持：读取系统配置 `multimodal_model_name`。
3. 配置为空、未启用、类型不是多模态：停止执行，提示不支持图片理解，并说明可配置默认多模态模型。
4. 配置有效：用该模型看图（OCR / 图表 / 布局），不回答用户问题；把结果写入本轮用户消息的 `<vision_sidecar>` 块；原模型继续只吃文字。
5. 解析失败：降级提示「系统默认多模态解析失败」。
6. 旁路成功：思维链记录解析步骤，回复开头告知已改用默认多模态解析；历史轮次通过 sidecar 块保留图意，供追问复用。

## 配置

- 键：`multimodal_model_name`
- 分类：`agent`（与 `llm_model_name` 同组）
- 默认：空（未配置）
- 下拉：注册表中启用的 `multimodal` / `vision` / `image2text`

## 非目标

- 不把整轮主模型换成多模态模型
- 不改变非图片附件路径
- 当前模型类型未知时仍先走上游 API，不提前旁路
