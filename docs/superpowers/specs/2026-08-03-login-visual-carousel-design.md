# NanZi 登录页品牌主视觉轮播设计

## 1. 目标

在不影响登录效率、品牌配置和移动端可用性的前提下，将登录页左侧主视觉升级为 NanZi 品牌故事轮播：

- 以 A×C Logo 为统一识别核心。
- 用三块视觉章节表达“可信入口 → 智能平台 → 开放生态”。
- 保持右侧登录表单位置、宽度和交互稳定，避免轮播干扰登录。
- 支持多屏自动切换，同时保留手动选择和减少动画的可访问体验。

## 2. 已确认的视觉方向

采用“B 为默认视觉 + 首屏轻随机 + 固定顺序轮播”。

### 2.1 统一品牌名称

- A、B、C 三个章节的 Logo 旁品牌名称统一显示为 `NanZi · 智能体平台`。
- 品牌名称下方保留英文辅助副标题 `Your Intelligent Agent Platform`，三屏共用且字号、位置保持稳定。
- 英文副标题不承担章节叙事；章节主标题、描述和能力标签使用中文视觉文案表达当前章节主题。
- 当系统设置中的“品牌个性化”开关为关闭时，始终使用默认名称 `NanZi · 智能体平台`。
- 当“品牌个性化”开关为开启且配置了产品名称时，三个章节统一显示配置的产品名称，不再按章节显示不同产品名。
- 当品牌个性化启用且配置了登录副标题时，英文辅助副标题使用系统设置中的登录副标题；未配置时回退到 `Your Intelligent Agent Platform`。
- 章节之间可以切换不同的主标题、描述和能力标签，但不能切换品牌名称。
- 这里的品牌名称与 Logo 是稳定锚点；A/B/C 的差异只体现在背景、主标题、描述、能力标签和装饰层。
- 品牌锁定区固定在左侧主视觉面板的左上角；中间区域只承载当前章节的主标题和能力内容。

### B：浅色可信主视觉（默认首屏）

- 关键词：可信、企业、自然语言到结果。
- 视觉：浅蓝背景、白色登录卡片、轻量智能连接线和节点。
- 文案方向：`从自然语言到可执行结果`。
- 作用：首次进入时降低距离感，适合企业客户和业务用户。

### A：深色科技主视觉

- 关键词：平台、编排、品牌力量。
- 视觉：深蓝网格、蓝紫光晕、完整 NanZi Logo 与能力标签。
- 文案方向：`让智能体成为组织的第二操作系统`。
- 作用：强化平台定位和 NanZi 的主品牌记忆。

### C：智能生态主视觉

- 关键词：智能体、工具、知识、协同网络。
- 视觉：深色紫蓝空间、少量节点和连线，不使用密集电路板图案。
- 文案方向：`一个入口，连接所有智能能力`。
- 作用：表达开放生态和多智能体协作能力。

实现时使用公开品牌配置中的 `enabled` 与 `product_name` 字段决定统一品牌名称；品牌个性化关闭时由登录页使用默认展示名称兜底。现有后端公开品牌接口已经提供这两个字段，登录页不需要新增配置接口。

## 3. 轮播行为

### 首屏选择

- 每次浏览器会话首次进入时，在 B 为主的三个章节中轻量随机选择首屏，避免所有用户永远看到同一张画面。
- 随机只影响首屏，不改变章节设计和后续顺序。
- 如果品牌配置提供自定义登录主视觉，继续由品牌配置优先；本方案只定义默认主视觉。

### 固定顺序

首屏确定后，按以下循环顺序播放：

```text
B → A → C → B
A → C → B → A
C → B → A → C
```

这样既有新鲜感，也保持品牌叙事的可预测性。

### 时间与交互

- 每屏停留 7 秒。
- 使用约 700–900ms 的渐隐和轻微水平位移过渡。
- 底部显示三个圆点指示器，允许用户直接切换。
- 鼠标悬停在左侧主视觉、登录表单获得焦点或用户正在输入时暂停自动播放。
- 用户手动切换后，重新计时当前屏幕，不立即跳转到下一屏。
- 登录成功、路由离开或组件卸载时清理定时器。

## 4. 页面结构

```text
Login
├── BrandVisualPanel
│   ├── VisualBackground
│   ├── VisualChapter
│   │   ├── NanZi Logo / wordmark
│   │   ├── title
│   │   ├── subtitle / description
│   │   └── capability tags
│   ├── ChapterIndicators
│   └── SystemStatus (可选，仅桌面端)
└── LoginPanel
    ├── MobileBrandHeader
    ├── LoginTabs
    ├── LoginForm
    └── Copyright / legal text
```

右侧 `LoginPanel` 不随主视觉章节变化，登录接口、SSO、API Key、动态品牌配置和错误提示保持现有行为。

## 5. 品牌资源使用规则

- 主视觉使用当前品牌 `icon_url` 作为图标，再以动态文字显示品牌名称；默认资源回退到 `docs/brand/nanzi-n-icon.svg`，不使用写死产品名的静态 wordmark 作为动态品牌标题。
- 图标旁的品牌名称在三屏中使用同一个解析结果，默认显示 `NanZi · 智能体平台`；品牌个性化启用后显示配置的产品名称。
- 英文副标题使用同一个解析结果，默认显示 `Your Intelligent Agent Platform`；品牌个性化启用后优先显示配置的登录副标题。
- 图标使用 `docs/brand/nanzi-n-icon.svg` 或 favicon 简化版，不添加白色外框。
- 背景只使用 NanZi 蓝、靛紫、青色节点和低饱和辅助色。
- 连接线和节点保持稀疏，第一眼仍然先读出 `N`。
- 不在主视觉中加入机器人脸、密集网络、电路板纹理或随机高饱和颜色。
- 登录页主视觉可以有光晕和网格，但不能让装饰覆盖标题、Logo 或表单。

## 6. 响应式与可访问性

- `lg` 以上显示完整左侧主视觉和右侧登录面板。
- 小于 `lg` 时隐藏复杂多屏主视觉，仅保留 B 章节的静态 Logo、产品名和一句短文案。
- 支持 `prefers-reduced-motion: reduce`：关闭自动轮播和位移动画，保留静态 B 章节与可点击指示器。
- 章节指示器使用按钮语义，包含可读的 `aria-label`，并标识当前章节。
- 动态文案切换不改变登录表单的焦点，不抢占键盘输入。
- 主视觉装饰层设置为 `aria-hidden`，避免屏幕阅读器读取纯装饰节点。

## 7. 验证标准

### 行为验证

- 默认进入登录页能看到一个完整主视觉章节和可用登录表单。
- 自动播放按 7 秒间隔切换，且不会创建重复定时器。
- 首屏随机后，后续始终遵循固定顺序。
- 悬停、输入和手动切换会暂停或重新计时，不影响登录提交。
- 动态品牌配置仍能覆盖产品名、登录副标题和 Logo。
- 登录成功、SSO、API Key、错误提示行为不变。

### 视觉验证

- A、B、C 三屏的色彩、Logo、标题和能力标签清晰可读。
- 右侧表单在切屏时不抖动、不改变宽度、不发生层级遮挡。
- 桌面端宽屏、窄屏和移动端均无水平滚动条。
- 头像、Logo 和主视觉资源无白边、破图或外部网络依赖。

### 测试建议

- 增加静态契约测试，锁定章节数量、默认 B、固定循环顺序和资源路径。
- 增加组件级测试，覆盖暂停、恢复、手动切换和卸载清理。
- 使用浏览器手动验收桌面端、移动端和 reduced-motion 三种状态。

## 8. 非目标

- 本次不改登录接口、认证流程、SSO 协议、品牌配置数据结构或登录表单布局。
- 本次不把 A/B/C 做成三个独立登录页面。
- 本次不引入新的图片生成依赖；背景装饰优先使用 CSS 和现有 SVG 资源。
