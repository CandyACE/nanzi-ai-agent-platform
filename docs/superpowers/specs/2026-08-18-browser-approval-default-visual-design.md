# 浏览器审批默认值与状态视觉优化设计

## 目标

新创建的服务端浏览器会话默认使用“自动执行”，同时让“安全确认”状态在右侧浏览器面板中更容易识别，并允许用户关闭说明提示而不改变审批策略。

## 范围与边界

- 只改变新建 `BrowserSession` 的默认审批模式。
- 复用已有会话时保留数据库中已有的 `approval_mode`，不做静默迁移。
- 浏览器的 `guarded/autopilot` 策略仍独立于聊天底部的全局“自动批准”。
- 不改变敏感字段人工输入、危险工具拒绝、浏览器地址校验等既有安全边界。

## 实现设计

### 后端会话默认值

在 `BrowserSessionService.open_or_resume()` 创建新 `BrowserSession` 时写入 `autopilot`。已有活动会话命中复用分支，继续返回原有策略。测试覆盖新会话默认值和复用会话不被覆盖。

### 面板状态表达

`BrowserPanel.vue` 在标题栏保留原生下拉框，并根据 `approvalMode` 动态显示状态徽章：

- `guarded`：琥珀色警示徽章“⚠ 安全确认”，并使用更明显的边框、背景和文字对比。
- `autopilot`：绿色成功徽章“✓ 自动执行”，表达当前会话已进入自动执行模式。

当模式为 `guarded` 时，在标题栏下方显示一个绝对定位的紧凑提示层，说明提交、删除、支付等高风险浏览器动作会等待确认。提示层包含关闭按钮，关闭只影响本地显示状态；切换模式进入 `guarded` 时重新显示，确保用户不会因旧的关闭动作而错过新的安全状态。

截图预览区域明确标注“远程页面截图｜不是网页本体”，并说明点击、滚轮、键盘会转发到远程浏览器；内部 `target_ref` 元素列表不再展示给普通用户，仍由后端 AI 工具链使用。截图连接后每 2 秒自动刷新，人工操作和页面导航完成后立即返回新快照；点击截图后将焦点交给画面容器，以便继续接收键盘事件。

### 数据流

```text
新建会话 -> BrowserSession.approval_mode=autopilot -> EmbedChat.attachBrowserSession()
复用会话 -> 保留数据库 approval_mode -> BrowserPanel 按真实状态渲染
用户切换 -> PUT /sessions/{id}/policy -> 父组件更新 -> 面板徽章/提示层同步
```

## 测试设计

- 服务层测试断言新会话默认为 `autopilot`。
- 服务层测试断言同一 Profile 复用已有会话时不覆盖其审批模式。
- 前端契约测试断言面板包含两种状态徽章、`showSafetyNotice` 关闭状态、关闭按钮和进入 `guarded` 时重显的逻辑。
- 运行后端浏览器会话/策略相关测试与前端契约测试；不启动应用服务。

## 风险与回滚

- 默认自动执行会放宽新会话的高风险点击拦截，这是用户明确要求的产品行为；状态徽章与提示层用于降低误操作风险。
- 如需回滚，只需将新会话创建默认值恢复为 `guarded`，视觉状态代码可独立保留。
