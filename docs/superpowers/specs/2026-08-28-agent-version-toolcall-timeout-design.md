# 智能体版本级工具调用超时设计

## 1. 目标

在现有全局 `agent_max_toolcall_timeout` 之外，为每个智能体版本增加可选的工具调用超时时间。版本未配置时继承全局配置；版本配置后仅对该版本生效，并按“版本级优先、全局次之”选择统一超时值。

## 2. 已确认规则

- 全局配置 `agent_max_toolcall_timeout` 继续使用 `1–3600` 秒，默认 `120` 秒。
- 版本级配置保存于 `ai_agent_versions`，字段名为 `toolcall_timeout_seconds`，允许为空。
- 版本级配置为空时继承全局值；有值时直接作为当前版本的超时值。
- 版本级配置允许 `1–86400` 秒，支持长时间工具任务。
- 生效配置按优先级选择：

  ```text
  effective_timeout = 版本配置值（非空） or 全局配置值 or 默认 120 秒
  ```

- 工具自身的默认/内部超时参数和调用参数不会覆盖已选定的统一配置值；统一包装会按选定值传入并等待。
- 缺失、空值、非法或越界的版本级值按“未配置”处理，继续继承全局；全局非法值仍回退 `120` 秒。
- 版本级配置只随发布版本进入运行时；历史版本没有该字段时保持继承全局的兼容行为。

## 3. 数据与运行时

### 3.1 持久化与接口

`AIAgentVersion` 增加可空整数字段 `toolcall_timeout_seconds`。创建、更新和响应 schema 同步支持该字段，并由 Pydantic 校验 `1–86400` 的整数；`null` 表示继承全局。MySQL 和 PostgreSQL 各新增一份独立迁移，只增加列，不执行数据库操作。

`ChatConfig` 携带发布版本的 `toolcall_timeout_seconds`。普通本地智能体通过活动发布版本解析；按版本 ID 解析时读取同一字段。无版本覆盖的旧行返回 `null`。

### 3.2 统一超时计算

统一策略模块继续在一次请求构建工具集合时读取一次全局配置，同时接收当前 `ChatConfig` 的版本级覆盖。先选择版本级值，版本级为空时回退全局值，最后才回退默认值。Assistant、Knowledge、ChatBI、工作区和 AgentScope 原生工具都使用同一个最终秒数。

对于带 `timeout` 输入参数的工具，参数单位仍按 schema 判断秒或毫秒；包装器会用已选定的统一配置重写该参数，不允许工具参数覆盖版本级或全局配置。外层 `asyncio.wait_for`、同步 callable 线程边界、异步生成器总时长和审计详情继续沿用现有实现。

## 4. 前端交互

在 `AgentVersionEditorDrawer.vue` 的“工具能力”页签顶部、搜索工具区域之前增加“智能体工具调用超时时间”卡片：

- 提供“跟随全局配置 / 使用智能体专属配置”的开关。
- 默认关闭，版本字段为 `null`，页面明确显示“跟随全局（默认 120 秒）”。
- 开启后默认填入 `120` 秒，显示可手动输入的数字框和 `− / +` 微调按钮，步长为 1 秒，范围 `1–86400`。
- 键盘输入和粘贴内容只保留十进制数字；失焦时将空值、0 和非法值恢复为 120，将大于 86400 的值裁剪为 86400。
- 关闭开关时清空版本字段；保存 payload 保留 `null`，由后端按继承全局处理。
- 已发布版本沿用现有只读规则；草稿和新版本可编辑。

该配置位于工具列表上方，和工具勾选保持同一版本表单，保存仍复用现有版本创建/更新接口。

## 5. 测试与验收

- 运行时单元测试覆盖：全局 300 与版本 120 得 120；全局 120 与版本 300 得 300；工具配置和工具参数不覆盖已选定的统一值；缺失版本值继承全局。
- Schema/服务测试覆盖：版本级 `null`、1、86400 合法；0、86401、小数、布尔和非数字拒绝或按继承语义处理。
- AgentManager 测试覆盖：创建、更新、活动版本和指定版本读取/回写该字段。
- MySQL/PostgreSQL 迁移契约测试覆盖新增列、可空属性、注释和幂等方言。
- 前端契约测试覆盖工具能力页签顶部位置、继承开关、数字输入、键盘/粘贴过滤、1–86400 边界和 payload 字段。
- 执行聚焦 pytest、`vue-tsc --noEmit` 和 `git diff --check`，不运行 `./dev.sh`、部署脚本或真实数据库迁移。

## 6. 非目标

- 不改变全局配置的 `1–3600` 范围和系统设置页面现有行为。
- 不为每个工具新增独立持久化配置页面；本次由版本级配置统一覆盖工具自身的超时参数。
- 不改变 `agent_max_iterations` 的轮数语义。
- 不承诺突破 AgentScope、MCP 服务、反向代理或外部数据源自身不可配置的硬超时。
