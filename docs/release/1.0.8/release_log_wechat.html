🚀 NanZi AI 开源智能体平台 · v1.0.8 重磅发布

主类型 · 会话资源与证据时效 · Embed 思考链 · 关键缺陷修复

项目声明

本项目为个人开源，供自由学习交流，遵循 MIT 开源协议，可自由分发。

「NanZi」来自我一直使用的网名（南孜），取「孜孜不倦」之意，寓意 AI 持续学习与进化。

GitHub Repository： RandyChen1985/nanzi-ai-agent-platform

v1.0.8 是一次以“智能体主类型、会话资源与本轮元数据集、证据时效、门户折叠体验、Embed 思考链升级”为核心的迭代，并集中修复一批线上缺陷。平台落地主类型与委派就绪；会话资源可持久化并支持本轮元数据集挂载；统一语义帧与证据时效；门户支持卡片折叠与更新时间；EmbedChat 强化思考链与交互入口；同时修复 MySQL 特殊密码、HTTP 中心白屏、剪贴板复制、权限缓存与时长异常硬拦截误杀等问题。

本次变更范围自 d824dc69（不含）至 68e85aba，共 100 个提交，涉及 351 个文件、约 30,517 行新增代码。

🚀 Key Features

01 🏷️ 智能体主类型与配置体验

●主类型落地：GENERAL / CHATBI / KNOWLEDGE_BASE；中心按类型筛选；委派就绪检查。

●欢迎卡片：版本级 welcome_config；配置完成度与规则提示优化。

●AI 润色：8 种范式润色；引擎/类型说明置顶模态框。

02 📦 会话资源、本轮元数据与资源目录

●范围持久化：会话资源范围校验强化并落库；门户挂载解耦路由。

●本轮挂载：元数据集本轮挂载优先于会话范围。

●资源目录工具：可访问资源目录 + 路由短路；轻量数据集列表与工具快照。

03 🛡️ 证据时效、语义帧与 ChatBI 路由

●语义帧：统一证据状态，阻断无据编造并透出时效。

●取时与路由：取时熔断、新问优先、来源感知资格判定与门控。

●时长 soft tip：负时延/极端延迟改为提示 + soft repair，不再硬拦截无答。

04 📊 门户折叠与数据源加固

●门户体验：数据集卡片完全折叠、更新时间展示、视觉文案精简。

●PostgreSQL：新增 PostgreSQL 数据源支持。

●运维：MySQL 特殊字符密码修复；权限变更失效 API Key 缓存。

05 💬 EmbedChat 思考链与聊天交互

●思考链：耗时渐变、折叠摘要、实时总耗时；移动端跟底滚动与触控优化。

●排版与入口：三套排版样式 Redis 持久化；专家胶囊、技能加号级联菜单。

●Embed：URL 锁定智能体；路由提示改 Toast；聊天日志 Markdown 导出。

06 🔔 通知、任务与 Skills

●通知中心：站内通知详情、任务结果可视化与调度兜底。

●Skills：公共 Skill 显式绑定智能体展示；剪贴板统一降级复制。

●业务简报：导出走 AI 正文为主并附证据附录。

07 🐛 关键缺陷修复（Bug Fixes）

●ChatBI / 运行时：时长异常改 soft tip；本轮元数据集路由；工具循环熔断锁存；工具快照空值崩溃；轮次成败误判；非流式消息重复。

●数据源 / 鉴权：MySQL 特殊字符密码；权限变更后 API Key 缓存失效；工具列表 API Key 可读；RAGFlow 原档下载。

●前端 / Embed：HTTP 智能体中心白屏；剪贴板复制；路由 Toast 防抖动；快捷按钮触控与思考序号裁切；AI 润色/向导门禁；门户误锁与列表布局。
