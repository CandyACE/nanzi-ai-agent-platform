### 版本二：极客硬核版（技术社区/群发）

> 想要随时人工接管的智能体？NanZi v1.0.13.0 支持浏览器“单击选定、双击执行”，验证码识别失败时可人工接管；同时补充报表、知识库和任务配置指引，让第一次使用也更容易上手。
