本次变更自 43c634f4 至 091236a1，共 59 个提交（52 个非 Merge 提交），变更 352 个文件。

🚀 核心更新亮点 (Key Features)

1. 🛡️ 安全沙箱多策略扩展与 Docker 预构建加速

  • 四大沙箱策略全面支持：系统配置新增 sandbox_policy，支持 local（本机）、docker（容器隔离）、e2b（云端安全沙箱）、ssh（远程主机）四类策略，动态展现专属参数。
  • Docker 沙箱工作区同绝对路径挂载：解决容器内 /workspace 与宿主机物理路径不一致导致的工件下载错位问题；支持直接挂载宿主机同名绝对路径并软链兼容。
  • Docker 镜像预构建加速：提供后台一键预构建端点，实现「首次分钟级预构建 + 后续秒级会话冷启动」；新增 sandbox_docker_manual_image_url 支持自定义远程镜像与多地域 Python 加速源预设。
  • Bash 执行环境探测与风险提示：自动识别当前服务运行环境（容器/宿主机），在前端输入框渲染自适应安全警示横幅，支持一键折叠与本地记忆。

【示例截图占位】：安全沙箱多策略配置、Docker 预构建状态与 Bash 宿主机警示横幅

2. 🌐 服务端持久化浏览器会话与实时人机协同面板

  • 持久化浏览器会话：基于 Playwright 构建用户级持久化浏览器工具套件（打开/快照/点击/输入/拖拽/多标签页）与数据库存储模型。
  • WebSocket 实时协同面板：前端右侧抽屉式浏览器面板支持实时画面流串流，用户可随时接管进行鼠标点击、拖拽、滚轮滚动与键盘输入。
  • 拟人滑块拖拽与 Stale 自动恢复：支持拟人贝塞尔缓入缓出轨迹与垂直抖动模拟；增加元素就绪等待与执行期 Transient Stale 异常自动刷新自愈机制。
  • 严格安全防护与缓存抹除：内置 SSRF 防护（拦截内网与元数据 IP）与高风险操作确认；支持在个人中心一键物理抹除浏览器底层数据目录。

📷

【示例截图占位】：右侧实时浏览器交互面板、拟人滑块拖拽与人机接管操作演示

3. 🧠 上下文预算管控、溢出压缩与水位线浮标

  • 预算管控与溢出压缩：引入 agent_context 预算管理，支持 Token 上限预设（16k~256k）；逼近上限时自动触发确定性摘录压缩与 LLM 语义摘要。
  • 结构化摘要（结论优先）：优先保留工具名与输出核心结论，剔除冗长入参；单工具块独立配额截断；多模态图片保留文件名信息。
  • 输入框上下文水位线浮标：聊天输入框右上角增加环形/徽标浮标，展示 Token 用量、预算占比与当前沙箱执行环境。
  • 物理窗口动态夹紧保护：请求输入逼近窗口时动态将 max_tokens 夹紧至可用空间，杜绝 API 超限报错。

4. 🧩 推理思考模型强制工具调用兼容层

  • 解决思考模型工具调用冲突：解决 DeepSeek-R1 / QwQ 等思考模型在强约束强制调用场景下先输出 <think> 导致的死循环与解析崩溃问题。
  • tool_choice_for_model 适配层：构建兼容适配层与 ThinkingToolChoiceCompatAgent，智能解析思考块并规范化 tool_call 分发。

5. 📦 AI 交付物工件与长效下载管理

  • 工件发布工具（publish_generated_file）：新增系统工具与 ai_artifacts 表，支持将工作区文件发布为结构化工件。
  • 7天下载有效期与前缀配置：下载链接默认有效期延长至 7 天；新增 file_download_url_prefix 支持自定义下载域名/前缀。

6. 💬 AI 主动提问与全卡片折叠交互重构

  • AI 主动提问交互（ask_user_question）：支持单选/多选/补充输入，通过独立卡片中断当前 ReAct，支持用户提交与取消拦截。
  • 全量卡片折叠交互：工具权限确认卡、外部执行卡、AI 提问卡与业务确认卡统一支持展开/折叠，完成状态自动折叠，消除长脚本霸屏。
  • TODO 清单常驻与记忆关闭：TODO 任务清单在输入框正上方常驻展示；全部完成自动折叠；手动关闭后持久化记忆。

7. 🤝 子代理独立会话委派与层级时间线

  • 专属会话隔离：子智能体使用独立 child_session_id 命名空间，父子通过 ID 严格关联。
  • 多层嵌套时间线：子代理步骤收拢在「调用子代理」父级容器下，支持分析、SQL 与工具调用分级展开；新增 list_available_agents 目录发现工具。

8. 🗃️ 元数据批量治理与聊天日志双 Tab

  • 元数据批量删除与 N+1 消除：支持数据表/指标/关系批量删除，优化跨库关系短路与权限查询性能。
  • 聊天日志「对话/轨迹」双 Tab：右侧详情区新增双 Tab 切换，所有 Step 节点补充 HH:mm:ss 触发时间。
  • Toast 淡彩微磨砂重构：微光淡彩渐变 + 状态色环境弥散阴影，视觉层次显著提升。

⚠️ 破坏性变更与升级注意事项 (Breaking Changes)

🚨 升级特别注意：

1. 必须执行数据库增量迁移：由于引入了沙箱多策略、浏览器持久化会话、工件表与上下文预算配置，升级后请务必执行 MySQL (V122~V129) 或 PostgreSQL (V22~V29)。
2. Docker 沙箱路径升级：若先前已挂载容器沙箱，现已统一对齐为宿主机同绝对路径挂载与软链兼容，无需手动做路径软链调整。

从 v1.0.11 升级至 v1.0.12 时，请特别注意以下变更：

📦 快速升级指南 (Upgrade Guide)

⚠️ 升级前置提醒：无论采用源码还是 Docker 升级，请务必先备份数据库，并在服务启动前执行数据库升级脚本！

方式一：源码直接升级（本地 / 虚机部署）

# 1. 拉取最新代码

git fetch origin && git checkout main && git pull origin main

# 2. 更新 Python 依赖

pip install -r requirements.txt

# 3. 执行数据库升级 (V122~V129)

./db-prod/apply-sql-native.sh # PG: ./db-prod-pg/apply-sql.sh

# 4. 重新编译前端并启动

cd frontend && npm install && npm run build && cd .. && ./dev.sh

方式二：Docker 容器化升级（生产环境 / 容器集群）

场景 A：从 Release 下载镜像离线加载（推荐）

# 1. 下载并加载镜像归档（按架构选择）

docker load -i nanzi-ai-agent_1.0.12_linux-amd64_*.tar # ARM: arm64_*.tar

# 2. 执行数据库升级

./db-prod/apply-sql-native.sh # PG: ./db-prod-pg/apply-sql.sh

# 3. 启动 / 重启容器

cd docker && ./start-nanzi-ai-agent.sh

场景 B：本地 / 服务器自主构建镜像

# 1. 拉取最新代码并执行数据库迁移

git pull origin main && ./db-prod/apply-sql-native.sh

# 2. 构建 v1.0.12 镜像并重启

cd docker && ./build_linux_x86.sh 1.0.12 # ARM: ./build_linux_arm.sh 1.0.12

./start-nanzi-ai-agent.sh
